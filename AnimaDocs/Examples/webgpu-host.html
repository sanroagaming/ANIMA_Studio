Host requirement

Use a WebGPU-capable browser and open this page over HTTPS or http://localhost. Opening the folder directly with a file:// URL or inside an opaque-origin iframe may disable the API. This page checks the real browser/device path and reports errors inline.

What this proves

ANIMA source can invoke an explicit gpu capability from click handlers. The bridge requests a device, dispatches a WGSL compute shader over numeric storage data, reads the result back, and draws a time-dependent WGSL fragment function to a canvas.

gpu.request();
gpu.computeDemo();
gpu.renderDemo("GpuCanvas");
gpu.stop();
WebGPU is hardware/browser dependent. Adapter identity may be withheld. The compute helper uses one read/write array<f32> storage binding and is intentionally small; use the host-side Anima.webgpu.requestDevice() API for custom resource layouts.
